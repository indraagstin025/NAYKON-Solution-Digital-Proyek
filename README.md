# NAYKON-Solution-Digital-Proyek

Website profil perusahaan (Corporate Website) **PT NAIKON Digital Solution** — Mitra rekayasa perangkat lunak, pembuatan website bisnis, aplikasi web kustom, dan pengembangan aplikasi mobile.

## Rute Halaman
- `/` — Beranda (Hero, Profil Singkat, Layanan Utama, Proses Kerja, Studi Kasus, Kontak)
- `/tentang-kami` — Profil Perusahaan, Komitmen Rekayasa, Visi & Misi
- `/layanan` — Spesialisasi Layanan Utama & Tahapan Proses Kerja
- `/portofolio` — Studi Kasus & Konsep Solusi Bisnis
- `/blog` — Ruang Artikel & Wawasan Teknologi
- `/kontak` — Saluran Komunikasi Resmi & Formulir Konsultasi Proyek

## Teknologi Utama
- **Framework**: Next.js (App Router) & React 19
- **Bahasa**: TypeScript
- **Styling**: Tailwind CSS v4
- **Ikonografi**: `@radix-ui/react-icons`

## Menjalankan Proyek Secara Lokal

```bash
npm install
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000) di browser untuk melihat hasilnya.
